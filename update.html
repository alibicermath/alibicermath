Website Editor — alibicer website

How to update your website (3 steps):
1. Make your changes below (add, edit, or delete items in any section).
2. Click the yellow Download updated cv-data.js button (top right).
3. Go to your GitHub repository page → click Add file → Upload files → drag in the downloaded cv-data.js → click Commit changes. Your website updates in about a minute.
Tip: to add a lab member's photo, also upload their picture file to the assets/members folder on GitHub, and type its path (e.g. assets/members/jane.jpg) in the Photo box.
